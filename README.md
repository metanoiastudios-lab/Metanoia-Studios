# Metanoia Studios — Web

## Cómo correrlo localmente

```bash
npm install
npm run dev
```

Abre `http://localhost:4321`. Deberías ver una página de prueba con los
swatches de color y las tipografías Space Grotesk / Inter cargando
correctamente.
